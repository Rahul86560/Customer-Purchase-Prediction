# Customer Purchase Prediction Project
This project analyzes customer behavior and predicts whether a user will make a purchase based on interaction events such as views, cart additions, and wishlist activity.

## Tools Used
- Databricks
- Python
- PySpark
- Scikit-learn
- Power BI

## Machine Learning Model
A Random Forest classifier was trained to predict purchase probability using features derived from event logs.

## Model Results
- Accuracy: ~65%
- Key influencing factor: Product views
